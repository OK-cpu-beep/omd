# Домашняя работа по Python: функции

Файл `funcs.py` формирует три отчёта по сотрудникам:

1. Иерархия департаментов и входящих в них команд.
2. Сводка по департаментам: количество сотрудников, минимальный, максимальный и средний оклад.
3. Запись сводки в CSV-файл.

Номер отчёта передаётся аргументом `var_num` в функцию `do_report()`.
Чтение файла и каждый отчёт вынесены в отдельные функции.

## Требования

Проверено на Python 3.13.7.

## Установка зависимостей

Дополнительные библиотеки не требуются.
Используются модули `csv` и `itertools` из стандартной библиотеки Python.

## Запуск

Поместите `Corp_Summary.csv` рядом с `funcs.py`.
Файл должен содержать заголовок и шесть колонок: ФИО, департамент, команда, должность, оценка, оклад.
Кодировка — UTF-8, разделитель — `;`.

Откройте терминал в этой папке и выполните:

```bash
python funcs.py
```

Программа выведет первые два отчёта в терминал и запишет третий в `output.csv`.
Некорректные записи пропускаются с сообщением о причине и номере строки.
