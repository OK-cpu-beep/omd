# Домашняя работа по Python: классы

Файл `hw_classes_base.py` содержит программу для выделения ключевых слов из текстов.
В ней реализованы четыре класса:

1. `CountVectorizer` — строит словарь и считает частоты слов или биграмм.
2. `BinaryVectorizer` — отмечает наличие слов или биграмм в тексте: 1 или 0.
3. `TfidfVectorizer` — рассчитывает веса TF-IDF или TF в зависимости от настройки `use_idf`.
4. `KeywordExtractor` — выбирает до `top_n` ключевых слов по убыванию веса, при равенстве — по алфавиту.

Метод `fit()` обучает векторизатор, `transform()` преобразует тексты по сохранённому словарю,
а `fit_transform()` выполняет оба действия. Настройка `lowercase` управляет приведением текста
к нижнему регистру, `ngram_size` — выбором слов или биграмм.

## Требования

Проверено на Python 3.13.7.

## Установка зависимостей

Дополнительные библиотеки не требуются.
Используется модуль `math` из стандартной библиотеки Python.

## Запуск

Откройте терминал в папке с `hw_classes_base.py` и выполните:

```bash
python hw_classes_base.py
```

Программа вызовет функцию `demo()` и выведет результаты трёх сценариев:

1. Обучение TF-IDF, вывод словаря, весов IDF и матриц для обучающих и проверочных текстов.
   Проверка, что очистка полученного списка `idf` не меняет сохранённые веса.
2. Расчёт TF с учётом регистра и без IDF, затем повторное обучение TF-IDF на новом корпусе.
3. Выделение ключевых слов при `top_n=2` и `top_n=1`, обработка ошибки при `top_n=0`.

Тексты для обучения и проверки заданы в списках `TRAIN_CORPUS` и `CHECK_CORPUS`
внутри файла. Вводить данные с клавиатуры и подготавливать отдельные файлы не требуется.
