# Домашняя работа по Python

Файл omd.py содержит решения пяти задач:
1. Операции с множествами товаров на складах в Москве, Казани.
2. Анализ истории поисковых запросов.
3. Анализ списка заказов.
4. Анализ статистики 5 дней работы магазина.
5. Анализ отзывов на товары.

## Требования

Проверено на Python 3.13.7

## Установка зависимостей

Дополнительные библиотеки не требуются.
Используются модули collections и itertools из стандартной библиотеки Python.

## Запуск

Откройте терминал в папке с omd.py и выполните:

```bash
python omd.py
```

Программа выполнит решения на примерах данных, заданных в файле omd.py,
и выведет результаты в терминал. Вводить данные с клавиатуры не требуется.
